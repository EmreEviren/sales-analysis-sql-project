# SQL Sales Analysis Project

Bu projede Superstore veri seti kullanılarak SQL ile satış analizi yapılmıştır.

## Proje İçeriği

Projede aşağıdaki analizler gerçekleştirilmiştir:

- Veri kontrolü
- Eksik veri kontrolü
- Duplicate kayıt kontrolü
- Genel KPI analizi
- Kategori analizi
- Şehir / bölge analizi
- Ürün analizi
- Müşteri analizi
- Window Function kullanımı
- CTE kullanımı

## Kullanılan SQL Konuları

- GROUP BY
- ORDER BY
- HAVING
- CASE WHEN
- Aggregate Functions
- Common Table Expressions (CTE)
- ROW_NUMBER()
- RANK()

## Kullanılan Veri Seti

- Sample Superstore Dataset

## Proje Çıktıları

- En yüksek satış yapan kategoriler analiz edildi.
- En kârlı ve zarar eden ürünler tespit edildi.
- Şehir ve bölge bazlı satış performansları incelendi.
- Yüksek değerli müşteriler analiz edildi.
- Kategori bazlı ürün sıralamaları oluşturuldu.

## Kullanılan Teknolojiler

- SQL Server
- T-SQL
